Cost is at Anthropic API list prices (what the same tokens would cost on the API); a Pro/Max plan is not billed this way. Reread is what the next message pays to read the whole conversation back in: warm while the cache is alive (cache-read price), cold once it has expired (the whole context is written to the cache again, at 1.25× input for a 5-minute cache or 2× for a 1-hour one). Cache life restarts on every message; it is counted from the last reply of the tab's main thread. Oversized marks a tab whose context is past the limit you pick: every further message rereads all of it, so /compact or a fresh tab with a handoff note is cheaper from there.
